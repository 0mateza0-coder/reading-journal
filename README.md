# สมุดบันทึกการอ่าน (PWA)

แอปบันทึกและสรุปการอ่าน ติดตั้งลงหน้าจอโฮมได้ ใช้แบบออฟไลน์ได้ และมีรอบทบทวน 1, 3, 7, 30 วัน

## ไฟล์ในโปรเจกต์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | โครงหน้าจอทั้งหมด: หน้าแรก บันทึก คลัง ทบทวน และตั้งค่า |
| `app.css` | หน้าตาแอป รองรับโหมดสว่างและโหมดมืด |
| `app.js` | การทำงานทั้งหมด: ล็อกอิน ซิงก์ บันทึก รอบทบทวน ค้นหา สำรองข้อมูล และแจ้งเตือน |
| `config.js` | ค่าเชื่อมต่อ Supabase (Project URL และ anon key) |
| `supabase/schema.sql` | คำสั่งสร้างตารางและสิทธิ์ใน Supabase |
| `sw.js` | Service Worker สำหรับใช้งานออฟไลน์ |
| `manifest.webmanifest` | ข้อมูลสำหรับติดตั้งเป็นแอป (ชื่อ ไอคอน สี) |
| `icons/` | ไอคอนแอป |

## ตั้งค่าระบบล็อกอิน (Supabase)

ถ้ายังไม่ตั้งค่า แอปจะทำงานแบบเก็บข้อมูลในเครื่องเท่านั้น และไม่มีหน้าล็อกอิน

1. สมัครที่ https://supabase.com แล้วกด **New project** (เลือก Region: Southeast Asia (Singapore))
2. ไปที่ **SQL Editor** → **New query** → วางเนื้อหาไฟล์ `supabase/schema.sql` → กด **Run**
3. ไปที่ **Authentication** → **URL Configuration**
   - **Site URL:** `https://mellow-maamoul-f21d56.netlify.app`
   - **Redirect URLs:** เพิ่ม `https://mellow-maamoul-f21d56.netlify.app/**`
4. ไปที่ **Project Settings** → **API** แล้วคัดลอก **Project URL** และคีย์ **anon public** มาใส่ใน `config.js`
   - ห้ามใช้คีย์ `service_role` ในไฟล์นี้
5. อัปโหลดโฟลเดอร์ขึ้น Netlify ใหม่

ระบบล็อกอินใช้ **อีเมล + รหัสผ่าน** สมัครแล้วต้องเปิดลิงก์ยืนยันในอีเมลก่อน และมีปุ่มลืมรหัสผ่าน

ถ้าเคยรัน `schema.sql` ไปแล้วก่อนมีการซิงก์เป้าหมาย ให้รันทั้งไฟล์อีกครั้ง (รันซ้ำได้ ไม่ลบข้อมูลเดิม) เพื่อสร้างตาราง `settings`

## ลองรันในเครื่อง

```bash
python3 -m http.server 8765
```

แล้วเปิด http://localhost:8765 ในเบราว์เซอร์

## ใช้บนมือถือ

Service Worker และการติดตั้งแอปต้องเปิดผ่าน **HTTPS** จึงต้องนำขึ้นโฮสต์ฟรีก่อน เช่น

- **GitHub Pages:** สร้าง repository แล้วอัปโหลดไฟล์ทั้งหมด จากนั้นไปที่ Settings → Pages แล้วเลือก branch `main`
- **Netlify Drop:** ลากโฟลเดอร์นี้ไปวางที่ https://app.netlify.com/drop

จากนั้นเปิดลิงก์บนมือถือ
- **iPhone:** เปิดใน Safari → ปุ่มแชร์ → "เพิ่มไปยังหน้าจอโฮม"
- **Android:** เปิดใน Chrome → เมนู → "ติดตั้งแอป"

## เมื่อแก้ไขไฟล์

เปลี่ยนเลข `CACHE` ใน `sw.js` (เช่น `v2` เป็น `v3`) ทุกครั้ง เครื่องที่ติดตั้งแอปไว้จะได้โหลดเวอร์ชันใหม่

## ข้อจำกัด

- ถ้าไม่ล็อกอิน ข้อมูลจะเก็บในเครื่องที่ใช้งานเท่านั้น ควรใช้ "ส่งออกไฟล์สำรอง" ในหน้าตั้งค่าเป็นระยะ
- ถ้าแก้บันทึกเดียวกันจากสองเครื่องพร้อมกันตอนออฟไลน์ การแก้ไขที่ซิงก์ทีหลังจะทับของก่อนหน้า
- แอปจะแจ้งเตือนเมื่อเปิดแอปเท่านั้น ถ้าต้องการให้แจ้งเตือนตอนแอปปิดอยู่ ต้องมีเซิร์ฟเวอร์ Push หรือทำเป็นแอปจริงด้วย React Native / Expo
